# Project: Security Incident Analysis Dashboard (SOC Data Analytics)
Project Objective
You are working as a SOC Data Analyst.
Task is to analyze security logs and answer:

* Which attacks occur most frequently?
* Which IPs are being targeted?
* What time do attacks peak?
* Which protocols are most abused?
* How are attacks trending over time?
* What recommendations can improve security?

### Business UnderStanding 
#### Scenario
A company recieves thousands of network events every day.

Management want a dash board showing: 

* Total incidents
* Attack distribution
* Top attacking IPs
* Most targeted servers
* Time-based attack trends

#### KPI Questions


| KPI | Description |
| :--- | :--- |
| Total Incidents | Total attacks detected |
| Attack Types | DOS, Port Scan, Brute Force |
| Top Source IP | Most active attacker |
| Top Destination IP | Most targeted system |
| Peak Hour | Highest attack volume |
| Protocol Usage | TCP/UDP/ICMP distribution |
